# Minimap character atlas

`minimap-glyphs.bin` contains the scale-1 pre-baked minimap character coverage data from the [Visual Studio Code minimap source](https://github.com/microsoft/vscode/blob/main/src/vs/editor/browser/viewParts/minimap/minimapPreBaked.ts) (ASCII 32–126 and the unknown-character fallback).
