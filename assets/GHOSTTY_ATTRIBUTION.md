# Ghostty terminal emulation

Terminal emulation uses libghostty-vt from Ghostty commit
`b40acce58dcf77df52231c3798ea58e924647c89` (MIT), through the community
`ghostty-vt` and `ghostty-vt-sys` Rust bindings 0.7.2 (Apache-2.0).
The bindings verify the official source archive against SHA-256
`a623aa0b1267594d9a1bb76a5fef535f198004e78730894f494a5bdc522a4850`.

Sources: https://github.com/ghostty-org/ghostty and
https://github.com/prabirshrestha/gpui-cn.

See GHOSTTY_LICENSE.txt and GHOSTTY_BINDINGS_LICENSE.txt beside this file.
